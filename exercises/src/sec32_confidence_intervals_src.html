# Define the variance estimator function
def var(sample):
    xbar = sum(sample) / len(sample)
    sumsqdevs = sum([(xi-xbar)**2 for xi in sample])
    return sumsqdevs / (len(sample)-1)

def dmeans(xsample, ysample):

dscores = dmeans(scoresR, scoresU)

Ellipsis

# @solution
# Obtain the sample sizes and stds of the two groups
nR, stdR = len(scoresR), scoresR.std()
nU, stdU = len(scoresU), scoresU.std()

# Calculate the standard error of the difference between means
seDscores = np.sqrt(stdU**2/nU + stdR**2/nR)

# Calculate the degrees of freedom
from ministats import calcdf
dfD = calcdf(stdU, nU, stdR, nR)

E3.22#

You calculate the 90% confidence interval \(\ci{\theta,0.9} = [\cil{\theta}, \ciu{\theta}]\) for the population parameter \(\theta\). Explain in your own words what \(\ci{\theta,0.9}\) means. What type of guarantee does \(\ci{\theta,0.9}\) provide?

Hint: Note the question is asking about \(\ci{\theta,0.9}\) and not \(\CI{\theta,0.9}\).

The 90% confidence interval \(\ci{\theta,0.9} = [\cil{\theta}, \ciu{\theta}]\) gives us a range of plausible numbers that we believe contains the true population parameter \(\theta\). In other words, we believe that \(\theta \in \ci{\theta,0.9}\). We can’t give any specific guarantee for the specific confidence interval \(\ci{\theta,0.9}\) we obtained in this analysis, but we know that the procedure we used to construct \(\ci{\theta,0.9}\) produces intervals that contain \(\theta\) in \(90\%\) of repeated samples.
