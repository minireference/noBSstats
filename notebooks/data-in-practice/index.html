Selecting only certain rows (filtering)¶

We often want to select a subset of the rows of a data frame that fit one or more criteria. This is equivalent to “filtering out” the rows that don’t satisfy these criteria. We use a two-step procedure for this:

  • Step 1: Build a “selection mask” series that consists of boolean values (True or False).

  • Step 2: Select the subset of rows from the data frame using the mask. The result is a new data frame that contains only the rows that correspond to the True values in the selection mask.

To select only rows where ezlvl is 1, we first build the boolean selection mask (Step 1)...

mask = players["ezlvl"] == 1
mask

... then select the rows using the mask (Step 2).

Tidy data¶

The concept of tidy data is a convention for organizing datasets that makes statistical calculations and visualizations easy to perform. Just like a tidy workplace, a tidy dataset makes it easy to find what you’re looking for. A data frame is organized according to the tidy data format if it has the following characteristics:

  • Each column contains the values for one variable.

  • Each row contains the values for one observation.

  • Each data cell contains a single value.

This specific organization of data into rows and columns makes it easy to perform statistical calculations on arbitrary subsets of the data, and allows us to create seaborn plots by mapping column names to visual aspects of the plot, as we saw many times in this section.

The students dataset is tidy¶

students = pd.read_csv("datasets/students.csv")
