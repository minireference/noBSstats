def fC(c):
    if c in ["heads", "tails"]:
        return 1/2

        return 0

Example 4: diagnostic test¶

def fV(v):
    if v == 1:
        return 0.03
    elif v == 0:
        return 0.97

def fTgivenV1(t):
    if t == 1:
        return 0.90
    elif t == 0:
        return 0.10

def fTgivenV0(t):
    if t == 1:
        return 0.20
    elif t == 0:
        return 0.80

def fTgivenV(t,v):
    if v == 1:
        return fTgivenV1(t)
    elif v == 0:
        return fTgivenV0(t)

def fTV(t,v):
    return fTgivenV(t,v) * fV(v)

for v in range(0,1+1):
    for t in range(0,1+1):
        print("Pr({T=" + str(t) + ",V=" + str(v)+"})",
              "=", fTgivenV(t,v), "*", fV(v),
              "=", round(fTV(t,v),4))
Pr({T=0,V=0}) = 0.8 * 0.97 = 0.776
Pr({T=1,V=0}) = 0.2 * 0.97 = 0.194
Pr({T=0,V=1}) = 0.1 * 0.03 = 0.003
Pr({T=1,V=1}) = 0.9 * 0.03 = 0.027

Bayes’ rule¶

Example 4: diagnostic test (continued)¶

We’re now interested in fV∣T(v∣t)f_{V|T}(v|t)fV∣T​(v∣t), which we can obtain using Bayes’ theorem.

fV∣T(v∣t)=fT∣V(t∣v)fV(v)fT∣V(t∣0)fV(0)+fT∣V(t∣1)fV(1).f_{V|T}(v|t) = \frac{ f_{T|V}(t|v) f_V(v) }{ f_{T|V}(t|0) f_V(0) + f_{T|V}(t|1) f_V(1)}.fV∣T​(v∣t)=fT∣V​(t∣0)fV​(0)+fT∣V​(t∣1)fV​(1)fT∣V​(t∣v)fV​(v)​.
(1)

We’ll now define the function fVgivenT that computes the numerator and denominator in this fraction, and returns the ratio.

def fVgivenT(v,t):
    num = fTgivenV(t,v) * fV(v)
    denom = fTgivenV(t,0) * fV(0) + fTgivenV(t,1) * fV(1)
    return num / denom

The probability of the patient having the virus fV∣T(1∣t=1)f_{V|T}(1|t=1)fV∣T​(1∣t=1), given they tested positive is:

fVgivenT(1,1)
0.12217194570135746

Intuitively, this percentage is measuring the ratio of the probability of the outcome fVT(1,1)f_{VT}(1,1)fVT​(1,1) divided by sum of the probabilities of all outcomes where positive test can occur: fVT(1,1)+fVT(0,1)f_{VT}(1,1)+f_{VT}(0,1)fVT​(1,1)+fVT​(0,1).

fTV(1,1) / (fTV(1,0) + fTV(1,1))
