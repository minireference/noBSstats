Cohen’s d standardized effect size¶

The effect size Δ\DeltaΔ we use in statistical design is usually expressed as a standardized effect size like Cohen’s ddd, which is defined as the observed “difference” divided by a standard deviation of the theoretical model under the null hypothesis.

One-sample case¶

For a one-sample test of the mean relative to a null model with mean μ0\mu_0μ0​, Cohen’s ddd is calculated as:

d=x‾−μ0sx,d = \frac{\overline{\mathbf{x}} - \mu_0}{ s_{\mathbf{x}} },d=sx​x−μ0​​,
(1)

where sxs_{\mathbf{x}}sx​ is the sample standard deviation.

When doing statistical design, we haven’t obtained the sample x\mathbf{x}x yet so we don’t know what its standard deviation sxs_{\mathbf{x}}sx​ will be, so we have to make an educated guess of this value, which usually means using the standard deviation of the theoretical model σX0\sigma_{X_0}σX0​​.

Two-sample case¶

For a two-sample test for the difference between means, Cohen’s ddd is defined as the difference between sample means divided by the pooled standard deviation:

d=x‾−y‾sp.d = \frac{\overline{\mathbf{x}} - \overline{\mathbf{y}} }{ s_{p} }.d=sp​x−y​​.
(2)

where the formula for the pooled variance is sp2=[(n−1)sx2+(m−1)sy2]/(n+m−2)s_{p}^2 = [(n -1)s_{\mathbf{x}}^2 + (m -1)s_{\mathbf{y}}^2]/(n + m -2)sp2​=[(n−1)sx2​+(m−1)sy2​]/(n+m−2).

When doing statistical design, we don’t know the standard deviations sxs_{\mathbf{x}}sx​ and sys_{\mathbf{y}}sy​ so we replace them with the theoretical standard deviations σX0\sigma_{X_0}σX0​​ and σY0\sigma_{Y_0}σY0​​ under the null hypothesis.

Recall table of reference values for Cohen’s ddd standardized effect sizes, suggested by Cohen in (Cohen YYYY TODO).

Cohen’s dEffect size
0.01very small
0.20small
0.50medium
0.80large

The formulas for sample size planning and power calculations we’ll present below are based on Cohen’s ddd.

This means you’ll have to express your guess about the effect size Δ\DeltaΔ as d=Δσ0d = \frac{\Delta}{\sigma_0}d=σ0​Δ​ where σ0\sigma_0σ0​ is your best about the standard deviation of the theoretical distribution.

Note Cohen’s ddd is based on the standard deviations of the “raw” theoretical population, and not standard error.

A conceptual amalgam of two ideas¶

Steps of the Neyman—Pearson hypothesis test¶

  1. Calculate the cutoff value CVα\text{CV}_{\alpha}CVα​.

  2. Calculate the test statistic t55t_{55}t55​ from the sample k55\mathbf{k}_{55}k55​.

  3. Apply the simplified decision rule that compares the test statistic to the cutoff value.

# 1. Calculate the critical value
from scipy.stats import t as tdist
rvT0 = tdist(df=n-1)
CV_alpha = rvT0.ppf(0.95)
CV_alpha

# 2. Calculate the test statistic
n = len(ksample55)
kbar55 = ksample55.mean()
sehat55 =  ksample55.std() / np.sqrt(n)
t55 = (kbar55 - 1000) / sehat55
t55
1.1024261132512938
# 3. Compare the test-statistic to the critical value
if t55 >= CV_alpha:

Steps of the Fisherian hypothesis test¶

  1. Calculate the test statistic t55t_{55}t55​.

  2. Calculate the ppp-value of the statistic from the sampling distribution under H0H_0H0​.

  3. Make a decision whether to reject H0H_0H0​ by comparing the ppp-value to the cutoff α=0.05\alpha=0.05α=0.05.

# 1. Calculate the test statistic
n = len(ksample55)
kbar55 = ksample55.mean()
sehat55 =  ksample55.std() / np.sqrt(n)
t55 = (kbar55 - 1000) / sehat55
t55
1.1024261132512938
# 2. Calculate the $p$-value
from scipy.stats import t as tdist
rvT0 = tdist(df=n-1)
pvalue55 = 1 - rvT0.cdf(t55)   # right-tailed p-value
pvalue55

We see the results of the Neyman–Pearson and Fisherian decision rules are the same. Indeed, we’ll always come to the same decision, whether we use criterion p<αp < \alphap<α in the space of ppp-values, or the t55≥CVαt_{55} \geq \text{CV}_{\alpha}t55​≥CVα​ in the space of ttt-values.
