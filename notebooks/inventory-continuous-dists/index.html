The uniform distribution U(α,β)\mathcal{U}(\alpha,\beta)U(α,β) is described by the following probability density function:

pX(x)={1β−αfor α≤x≤β,0for x<0 or x>1.p_X(x) = \begin{cases} \frac{1}{\beta-\alpha} & \textrm{for } \alpha \leq x \leq \beta, \\ 0 & \textrm{for } x<0 \textrm{ or } x>1. \end{cases}pX​(x)={β−α1​0​for α≤x≤β,for x<0 or x>1.​

Simulating other random variables¶

We can use the uniform random variable to generate random variables from other distributions. For example, suppose we want to generate observations of a coin toss random variable which comes out heads 50% of the time and tails 50% of the time.

We can use the standard uniform random variables obtained from random.random() and split the outcomes at the “halfway point” of the sample space, to generate the 50-50 randomness of a coin toss. The function flip_coin defined below shows how to do this:

def flip_coin():
    u = random.random()  # random number in [0,1]
    if u < 0.5:
        return "heads"
    else:
        return "tails"
# simulate one coin toss
flip_coin()
'heads'
# simulate 10 coin tosses
[flip_coin() for i in range(0,10)]
['tails', 'tails', 'heads', 'heads', 'tails', 'heads', 'heads', 'tails', 'heads', 'tails']

from scipy.stats import expon

lam = 7
rvE = expon(loc=0, scale=1/lam)

Normal distribution¶

A random variable NNN with a normal distribution N(μ,σ)\mathcal{N}(\mu,\sigma)N(μ,σ) is described by the probability density function:

fN(x)=1σ2πe−(x−μ)22σ2.f_N(x) = \tfrac{1}{\sigma\sqrt{2\pi}} e^{\small -\tfrac{(x-\mu)^2}{2\sigma^2}}.fN​(x)=σ2π​1​e−2σ2(x−μ)2​.
(3)

The mean μ\muμ and the standard deviation σ\sigmaσ are called the parameters of the distribution. The math notation N(μ,σ)\mathcal{N}(\mu, \sigma)N(μ,σ) is used to describe the whole family of normal probability distributions.

from scipy.stats import norm
