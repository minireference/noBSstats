Welch’s two-sample t-test

The goal of Welch’s two-sample ttt-test to check if the means two unknown population X∼N(μX,σX)X \sim \mathcal{N}(\mu_X, \sigma_X)X∼N(μX​,σX​) and Y∼N(μY,σY)Y \sim \mathcal{N}(\mu_Y, \sigma_Y)Y∼N(μY​,σY​) are the same or different.

Data¶

Two samples of numerical observations x=[x1,x2,…,xn]\mathbf{x}=[x_1, x_2, \ldots, x_n]x=[x1​,x2​,…,xn​] and y=[y1,y2,…,ym]\mathbf{y}=[y_1, y_2,\ldots, y_m]y=[y1​,y2​,…,ym​] from independent populations.

Assumptions¶

We assume the unknown populations are normally distributed (NORM)\textbf{(NORM)}(NORM), or the sample is large enough (LARGEn)\textbf{(LARGEn)}(LARGEn), so that the sampling distributions of the means in the two populations will be approximately normally distributed:

X‾∼N(μX,σXn)andY‾∼N(μY,σYn),\overline{\mathbf{X}} \sim \mathcal{N}\left(\mu_X, \frac{\sigma_X}{n}\right) \qquad \text{and} \qquad \overline{\mathbf{Y}} \sim \mathcal{N}\left(\mu_Y, \frac{\sigma_Y}{n}\right),X∼N(μX​,nσX​​)andY∼N(μY​,nσY​​),
(1)

where σX\sigma_XσX​ and σY\sigma_YσY​ are the standard deviations of the unknown populations.

Hypotheses¶

H0:μX=μYH_0: \mu_X = \mu_YH0​:μX​=μY​ and HA:μX≠μYH_A: \mu_X \neq \mu_YHA​:μX​=μY​.

Estimates¶

Compute the sample means x‾=mean(x)=1n∑i=1nxi\overline{\mathbf{x}} = \Mean(\mathbf{x}) = \frac{1}{n}\sum_{i=1}^n x_ix=mean(x)=n1​∑i=1n​xi​, y‾=mean(y)=1m∑i=1myi\overline{\mathbf{y}} = \Mean(\mathbf{y}) = \frac{1}{m}\sum_{i=1}^m y_iy​=mean(y)=m1​∑i=1m​yi​, and the observed difference between means d^=dmeans(x,y)=x‾−y‾\hat{d} = \DMeans(\mathbf{x}, \mathbf{y}) = \overline{\mathbf{x}} - \overline{\mathbf{y}}d^=dmeans(x,y)=x−y​.

We need to also compute the standard deviations sx=std(x)=1n−1∑i=1n(xi−x‾)2s_{\mathbf{x}} = \Std(\mathbf{x}) = \sqrt{ \frac{1}{n-1}\sum_{i=1}^n (x_i-\overline{\mathbf{x}})^2 }sx​=std(x)=n−11​∑i=1n​(xi​−x)2​ and sy=std(y)=1m−1∑i=1m(yi−y‾)2s_{\mathbf{y}} = \Std(\mathbf{y}) = \sqrt{ \frac{1}{m-1}\sum_{i=1}^m (y_i-\overline{\mathbf{y}})^2 }sy​=std(y)=m−11​∑i=1m​(yi​−y​)2​, which are estimates for the unknown population standard deviations σX\sigma_XσX​ and σY\sigma_YσY​.

Formulas¶

The estimated standard error of the difference-between-means estimator is

se^d^  =  se^x‾2+se^y‾2=sx2n+sy2m,\stderrhat{\hat{d}} \; = \; \sqrt{ \stderrhat{\overline{\mathbf{x}}}^2 + \stderrhat{\overline{\mathbf{y}}}^2 } = \sqrt{ \tfrac{s_{\mathbf{x}}^2}{n} + \tfrac{s_{\mathbf{y}}^2}{m} },se^d^​=se^x2​+se^y​2​​=nsx2​​+msy2​​​,
(2)

where sxs_{\mathbf{x}}sx​ and sys_{\mathbf{y}}sy​ are the sample standard deviations.

The Welch--Satterthwaite formula for the degrees of freedom parameter νd\nu_dνd​ is

νd    =    (se^x‾2+se^y‾2)2se^x‾4n−1+se^y‾4m−1.\nu_d \;\; = \;\; \frac{ \big(\stderrhat{\overline{\mathbf{x}}}^2 + \stderrhat{\overline{\mathbf{y}}}^2\big)^2 } { \tfrac{\stderrhat{\overline{\mathbf{x}}}^4}{n-1} + \tfrac{\stderrhat{\overline{\mathbf{y}}}^4}{m-1} }.νd​=n−1se^x4​​+m−1se^y​4​​(se^x2​+se^y​2​)2​.
(3)

In Python, we can calculate νd\nu_dνd​ by calling the helper function calcdf: νd=calcdf(sx,n,sy,m)\nu_d = \tt{calcdf}(s_{\mathbf{x}}, n, s_{\mathbf{y}}, m)νd​=calcdf(sx​,n,sy​,m).

Test statistic¶

Compute the ttt-statistic t=d^−0se^d^t = \frac{\hat{d} - 0}{ \stderrhat{\hat{d}} }t=se^d^​d^−0​.

Sampling distribution¶

Student’s ttt-distribution with νd\nu_dνd​ degrees of freedom, where the degrees of freedom parameter is computed using the helper function calcdf: νd=calcdf(sx,n,sy,m)\nu_d = \tt{calcdf}(s_{\mathbf{x}}, n, s_{\mathbf{y}}, m)νd​=calcdf(sx​,n,sy​,m), which implements the Welch--Satterthwaite formula.

P-value calculation¶

To obtain the ppp-value, we first compute the observed ttt-statistic, then calculate the tail probabilities in the two tails of the standard normal distribution T0∼T(νd)T_0 \sim \mathcal{T}(\nu_d)T0​∼T(νd​).

Let’s look at the source code of the function ttest_dmeans, which performs the steps of the two-sample t-test.

import numpy as np
from scipy.stats import t as tdist
from ministats import mean, std, calcdf, tailprobs

def ttest_dmeans(xsample, ysample, alt="two-sided"):
    """
    T-test to detect difference between two populations means
    based on the difference between sample means.
    """
    # Calculate the observed difference between means
    obsdhat = mean(xsample) - mean(ysample)

    # Calculate the sample sizes and the stds
    n, m = len(xsample), len(ysample)
    sx, sy = std(xsample), std(ysample)

    # Calculate the standard error, the degrees of
    # freedom, the null model, and the t-statistic
    seD = np.sqrt(sx**2/n + sy**2/m)
    obst = (obsdhat - 0) / seD
    dfD = calcdf(sx, n, sy, m)
    rvT0 = tdist(df=dfD)

    # Calculate the p-value from the t-distribution
    pvalue = tailprobs(rvT0, obst, alt=alt)
    return pvalue

See Section 3.5 in the No Bullshit Guide to Statistics for the detailed explanation of these steps. You can also check out the section Analytical approximation methods in the notebook notebooks/35_comparing_two_populations.ipynb.

To perform the two-sample ttt-test on the samples xs and ys, we call ttest_dmeans(xs, ys) or ttest_ind(xs, ys, equal_var=False), as we’ll show in the Examples section below.

Effect size estimates¶

from ministats import ci_dmeans
import numpy as np
from scipy.stats import t as tdist
from ministats import calcdf

def ci_dmeans(xsample, ysample, alpha=0.1):
    """
    Compute confidence interval for the difference between population means.
    """
    stdX, n = np.std(xsample, ddof=1), len(xsample)
    stdY, m = np.std(ysample, ddof=1), len(ysample)
    dhat = np.mean(xsample) - np.mean(ysample)
    seD = np.sqrt(stdX**2/n + stdY**2/m)
    dfD = calcdf(stdX, n, stdY, m)
    t_l = tdist(df=dfD).ppf(alpha/2)
    t_u = tdist(df=dfD).ppf(1-alpha/2)
    return [dhat + t_l*seD, dhat + t_u*seD]

We’ll now generate a samples of size n=20n=20n=20 from each of these populaitons and store them in a Pandas data frame called data.

from scipy.stats import norm

np.random.seed(42)

n = 20   # sample size

# Sample A: size = 20, population = N(104,3)
avals = norm(104,3).rvs(n)
dataA = pd.DataFrame({"pop":["A"]*n, "val":avals})

# Sample B: size=20, population = N(100,5)
bvals = norm(100,5).rvs(n)
dataB = pd.DataFrame({"pop":["B"]*n, "val":bvals})

# Sample C: size=20, same population as Sample B
cvals = norm(100,5).rvs(n)
dataC = pd.DataFrame({"pop":["C"]*n, "val":cvals})

data = pd.concat([dataA, dataB, dataC])

Example 1: populations are different¶

We’ll now apply the Welch’s two-sample t-test to compare the samples from population A and B, which we know are different.

avals = data[data["pop"]=="A"]["val"]
bvals = data[data["pop"]=="B"]["val"]

The dataset outliers2.csv consists of measurements of “soil score” variable using a specialized equipment for calculating soil quality.

The measurement apparatus has an upper limit beyound which it doesn’t function properly, so all observations that exceed this limit are recorded as the value 2500.

The effect of the outliers in group B is to pull the mean up, to a much higher value than where the other data points are.

from scipy.stats import ttest_ind

scoresA = outliers2[outliers2["group"]=="A"]["score"]
scoresB = outliers2[outliers2["group"]=="B"]["score"]
obst, pvalue = ttest_ind(scoresA, scoresB, equal_var=False)
pvalue
0.028387263383781086

The outliers pull the mean in group B to a high value, which leads us to conclude there is a statistically significant difference between the two groups. This is because we’re using the ttt-test when the normality assumption is not valid.
